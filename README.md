# 个人房产中介记账本

这是一个本地运行的房产中介经营记账项目，不需要 API key。数据默认保存在浏览器 `localStorage` 中，适合先快速试用核心流程。

## 当前功能

- 小区管理：新建小区，按小区筛选经营数据。
- 房源管理：添加具体房产信息，记录出租状态、装修时间、家电、家具、租客、交租日期。
- 财务管理：记录收入和成本流水，自动统计收入、成本、净利润和利润率。
- 成本优化：根据空置、利润、最大成本项和租差生成经营建议。
- 到期提醒：自动列出 7 天内待交房租和已逾期房源。
- 每日简报：一键生成今日经营汇总和待交房租清单。

## 使用方式

直接打开 `index.html` 即可使用。

也可以在项目目录运行本地服务器：

```powershell
python -m http.server 5177
```

然后访问：

```text
http://localhost:5177
```
